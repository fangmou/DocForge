== 写作，本应如工程

在代码的世界里，我们有版本控制、模块化、自动化测试。

而在写作的世界里？大多是富文本、锁定格式、云端依赖。

**方谋文构**相信：写作应当像构建代码一样严谨、自由、可控。我们将软件工程的纪律赋予每一个文字工作者，让你用纯文本构建知识的殿堂。

***

== 为什么选择方谋文构？

=== 纯文本，永恒的载体

AsciiDoc 是你的笔，纯文本是你的纸。没有私有格式锁定，没有云服务商绑架。你的文字，永远属于你自己。十年后，任何一个文本编辑器都能打开它。

=== AI 不只是插件，是原生基因

不是"加一个 AI 窗口"，而是从架构层面深度集成。流式续写、智能润色、中英互译、要点总结——AI 与你的写作流程无缝融合。支持 OpenAI、Ollama、DeepSeek 等任何 OpenAI 兼容 API，本地模型亦无障碍。

=== 知识不是孤岛，而是网络

双向链接、反向引用、标签体系、知识图谱。每一个文档都是知识网络中的节点，每一次写作都在编织你的第二大脑。用工程师的方式管理知识。

=== 安全，因为一切都在本地

你的文字不会离开你的电脑。AI 请求由 Rust 后端代理，API 密钥从不暴露给浏览器。没有注册账号，没有云端同步，没有数据收集。你的隐私，天经地义。

=== 可扩展，因为你的需求在进化

Worker 沙箱隔离的插件系统，让你可以安全地扩展编辑器的每一个角落。文档处理钩子、UI 渲染扩展、导出格式插件、AI 动作扩展——方谋文构是一个平台，不是一个终点。

=== 轻量，因为工具不该是负担

安装包不到 20MB，运行时内存占用极低。Tauri v2 + Rust 后端，告别 Electron 的内存黑洞。启动即用，无需等待。

== 适合谁？

- **技术写作者**：用工程化的方式编写文档、手册、技术博客
- **知识工作者**：构建个人知识库，让想法形成网络
- **开发工程师**：纯文本 + 版本控制，文档即代码（Docs-as-Code）
- **研究人员**：学术论文笔记、文献管理、研究日记
- **内容创作者**：长文写作、专栏撰写，AI 辅助提升效率

== 使用场景

=== 技术文档编写

为开源项目编写文档。AsciiDoc 格式直接进入 Git 仓库，CI/CD 自动构建发布。比 Markdown 更强大，比 Word 更可控。

=== 个人知识库

用双向链接连接笔记，用标签体系组织分类，用知识图谱发现隐藏关联。你的第二大脑，由你完全掌控。

=== AI 辅助写作

写技术博客时让 AI 帮你润色，写英文文档时让 AI 帮你翻译。本地模型通过 Ollama 运行，数据完全不出本机。

=== 团队文档协作

AsciiDoc 纯文本格式完美适配 Git 版本控制。团队成员用任何编辑器都能查看差异、解决冲突。方谋文构只是你的首选武器。

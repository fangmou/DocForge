// 插件系统概览
// 扩展点定义和已注册插件

NOTE: 当前版本已实现插件的 Worker 沙箱加载、扩展点注册与管理面板；以下扩展点均为 *规划项*，尚未接入宿主——插件声明后暂不会在编辑器中生效，后续版本将逐步接入。

[cols="1,2,2a"]
|===
| 扩展点 | 说明 | 示例用途
| `toolbar` | 工具栏按钮 | 自定义工具按钮
| `ai-action` | AI 操作 | 自定义 AI 操作（如代码解释）
| `exporter` | 导出格式 | PDF、DOCX、EPUB 导出
| `keybinding` | 快捷键 | 自定义键盘快捷键
| `editor-extension` | 编辑器扩展 | CodeMirror 扩展
| `preview-enhancer` | 预览增强 | Mermaid 图表渲染
| `sidebar-panel` | 侧栏面板 | 标签面板、搜索面板
| `status-item` | 状态栏项 | 自定义状态信息
|===

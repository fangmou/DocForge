= 方谋文构 (Fangmou DocForge) 用户手册
:toc: left
:toclevels: 3
:sectnums:
:sectnumlevels: 3

本手册涵盖方谋文构的全部功能，包括编辑器、预览、AI 助手、知识网络、导出、插件扩展和自定义标记等。


== 安装与启动

=== 系统要求

[cols="1,3"]
|===
| 操作系统 | Windows 10+、macOS 12+、Linux (glibc 2.31+)
| 运行时 | 无需安装 Node.js 或浏览器，应用内嵌 WebKit
| 可选组件 | asciidoctor-pdf（PDF 导出）、pandoc（DOCX 导入/导出）、asciidoctor-diagram（图表支持）
|===

=== 安装方式

从发布页面下载对应平台的安装包：

- **Windows**: `.msi` 安装程序
- **macOS**: `.dmg` 磁盘映像
- **Linux**: `.deb` / `.rpm` 包或 AppImage

=== 首次启动

. 启动应用后，点击侧栏的 *打开目录* 按钮，选择一个文件夹作为工作区。
. 工作区目录下会自动创建 `.docforge/` 配置目录，用于存储工作区状态、插件等。
. 点击 *新建文件*（`Ctrl+N`）创建第一篇文档，开始编辑。


== 界面概览

方谋文构采用经典的 *侧栏 + 编辑器 + 预览* 三栏布局。

image::interface-layout.png[界面布局示意]

[cols="1,4"]
|===
| **侧栏** | 文件树浏览、最近文件列表、工作区切换。支持右键菜单（新建 / 重命名 / 删除文件和文件夹）。拖拽分隔线可调整宽度。
| **编辑器** | CodeMirror 6 驱动的文本编辑器，支持 AsciiDoc 和 Markdown 双格式语法高亮、自动补全、Vim 模式。
| **预览面板** | 实时渲染 AsciiDoc / Markdown，也支持图片、音视频、PDF 等二进制文件预览。
| **工具栏** | 文件操作、编辑操作、格式标记、导出、面板切换等常用功能。
| **状态栏** | 显示文件路径、行列号、字数统计、文件类型、反向链接数、标签数、视图模式和 Vim 模式状态。
|===


== 编辑文档

=== 创建与打开

[cols="1,3"]
|===
| 新建文件 | `Ctrl+N` 或工具栏 *文件 → 新建*，在当前目录创建新文档
| 打开文件 | 在侧栏文件树中单击文件；或 `Ctrl+P` 使用模糊搜索快速打开
| 关闭标签 | `Ctrl+W` 关闭当前标签页
| 保存文件 | `Ctrl+S` 保存当前文件
|===

=== 格式识别

编辑器根据文件扩展名自动识别格式：

[cols="1,3"]
|===
| AsciiDoc | `.adoc`、`.asciidoc`
| Markdown | `.md`、`.markdown`
| 其他文本 | `.txt`、`.html`、`.svg` 等，以纯文本方式编辑
| 二进制文件 | `.png`、`.jpg`、`.mp4`、`.pdf` 等，仅预览不可编辑
|===

=== 语法高亮与补全

编辑器提供以下智能补全：

- **块语法补全** — 输入 `[` 后弹出块类型列表（source、quote、note、tip、warning 等）
- **行内语法补全** — 输入标记符号后自动配对
- **属性补全** — 输入 `{` 后补全文档属性
- **表格补全** — 自动对齐表格列

=== 视图模式

通过快捷键或状态栏按钮在三种视图间切换：

[cols="1,1,3"]
|===
| 分栏视图 | `Alt+Shift+1` | 左侧编辑器 + 右侧预览，默认模式
| 纯编辑 | `Alt+Shift+2` | 全屏编辑器，无预览
| 纯预览 | `Alt+Shift+3` | 全屏预览，适合阅读
|===

快捷键 `Alt+P` 可在三态之间循环切换。

可在 *设置 → 编辑器 → 默认视图模式* 中指定启动时的默认视图。

=== Vim 模式

方谋文构内置 Vim 编辑模式：

. 快捷键 `Alt+V` 或 *设置 → 编辑器 → Vim 模式* 开启。
. 支持完整的 Normal / Insert / Visual 模式。
. 退出 Insert 模式的序列可在设置中配置（默认 `jk`）。
. 支持 `:w` 保存、`:q` 关闭标签等 Ex 命令。
- 状态栏右侧显示当前 Vim 模式（`NORMAL` / `INSERT` / `VISUAL`）。

=== 自动保存

在 *设置 → 编辑器 → 自动保存间隔* 中设置秒数（默认关闭，设为 0）。启用后，编辑器会在指定间隔后自动保存文件。

=== 自动换行

快捷键 `Alt+W` 切换编辑器自动换行。也可在设置中配置默认值。


== 格式标记

=== 内联标记

编辑器支持 AsciiDoc 和 Markdown 两种格式的内联标记。以下以 AsciiDoc 为主说明，括号内为 Markdown 对应语法。

[cols="1,1,2"]
|===
| **粗体** | `Ctrl+B` | `*粗体文本*`（Markdown: `**粗体**`）
| *斜体* | `Ctrl+I` | `_斜体文本_`（Markdown: `*斜体*`）
| `等宽` | `Ctrl+Shift+`` | `` `等宽文本` ``
| #高亮# | — | `#高亮文本#`（仅 AsciiDoc）
| ^上标^ | — | `^上标文本^`（仅 AsciiDoc）
| ~下标~ | — | `~下标文本~`（仅 AsciiDoc）
|===

=== 标题

AsciiDoc 使用 `=` 号表示标题层级，Markdown 使用 `#`：

[source,asciidoc]
----
= 文档标题（一级）
== 章节（二级）
=== 小节（三级）
==== 段落（四级）
===== 小段（五级）
----

=== 列表

[source,asciidoc]
----
* 无序列表项 1
** 嵌套项 1.1
* 无序列表项 2

. 有序列表项 1
.. 嵌套项 1.1
. 有序列表项 2
----

=== 块元素

[source,asciidoc]
----
// 代码块
[source,python]
----
def hello():
    print("Hello, World!")
----

// 引用块
[quote,雷锋]
____
人的生命是有限的，可是为人民服务是无限的。
____

// 注释块
////
这段内容不会出现在输出中。
////

// 提示块
[NOTE]
====
这是一个注意事项。
====
----

=== 链接与引用

插入链接快捷键 `Ctrl+K`，编辑器会根据当前文件格式自动插入对应语法：

[source,asciidoc]
----
// AsciiDoc 链接
https://example.com[链接文本]

// AsciiDoc 内部引用（双向链接）
<<other-doc.adoc#,其他文档>>

// Markdown 链接
[链接文本](https://example.com)

// Markdown 内部引用
[其他文档](other-doc.md)
----

=== 注释

[cols="1,1,3"]
|===
| 行注释 | `Ctrl+/` | 在行首添加 `// `（AsciiDoc）或 `<!-- -->`（Markdown）
| 块注释 | `Ctrl+Shift+/` | 包裹为 `////...////`（AsciiDoc）或 `<!-- ... -->`（Markdown）
|===


== 导出

方谋文构支持将文档导出为 HTML、PDF 和 Word (DOCX) 格式。

=== 导出操作

[cols="1,1,3"]
|===
| HTML | `Ctrl+Shift+E` | 由内置 asciidoctor.js 渲染，无需外部依赖
| PDF | `Ctrl+Shift+P` | 需要安装 `asciidoctor-pdf` 命令行工具
| DOCX | `Ctrl+Shift+D` | 需要 `asciidoctor-pdf` + `pandoc`，或通过 pandoc 直接转换
|===

可通过工具栏 *导出* 菜单或快捷键执行。导出成功后状态栏会显示路径链接，点击可直接打开文件。

=== 导出设置

==== 通用设置

在 *设置 → 导出 → 通用* 中配置：

[cols="1,3"]
|===
| 输出目录 | 导出文件的存放路径，默认与源文件同目录
| 输出文件名 | `title`（使用文档标题）或 `stem`（使用源文件名）
| 检测工具 | 点击 *检测* 按钮自动查找系统中已安装的 pandoc 等工具
|===

==== PDF 设置

在 *设置 → 导出 → AsciiDoc · PDF* 中配置：

[cols="1,3"]
|===
| PDF 主题文件 | 自定义 `.yml` 主题文件，控制字体、颜色、页面布局
| 页面大小 | 默认 A4，可选 Letter 等
| 字体目录 | 指定自定义字体目录（用于 CJK 字体等）
| 页脚居中文本 | 例如 `'{page-number}'` 显示页码
| 封面图片 | 首页封面图路径
| 标题页 Logo | 标题页 Logo 图片路径
| 水印图片 | 页面背景图片路径
|===

**PDF 主题文件示例**（`custom-theme.yml`）：

[source,yaml]
----
extends: default
font:
  family:
    - Noto Serif CJK SC
    - Noto Sans CJK SC
  size: 11
heading:
  font:
    family: Noto Sans CJK SC
  h1-size: 24
  h2-size: 20
page:
  size: A4
  margin: [2.5cm, 2cm, 2.5cm, 2cm]
footer:
  center:
    content: "{page-number}"
----

==== Word 设置

在 *设置 → 导出 → AsciiDoc · Word* 中配置：

[cols="1,3"]
|===
| 参考文档 | 指定 `.docx` 模板文件，导出时继承其样式（字体、标题样式、页边距等）
|===

=== 导入

通过工具栏 *文件 → 导入 DOCX* 将 Word 文档转换为 AsciiDoc 格式。需要安装 `pandoc`。

=== 导出历史

所有导出记录自动保存在导出历史面板中。每次导出记录包含：

- 导出时间和格式
- 源文件和输出路径
- 快捷操作：打开文件、复制路径、在文件管理器中显示


== AI 助手

方谋文构深度集成 AI 能力，支持任何 OpenAI 兼容 API。

=== 配置 AI 服务

在 *设置 → AI 助手* 中配置：

[cols="1,3"]
|===
| API 端点 | 服务地址，如 `https://api.openai.com`、`http://localhost:11434`（Ollama）
| API Key | 认证密钥，本地保存，不会上传到任何第三方服务
| 模型 | 模型名称，如 `gpt-4o`、`deepseek-chat`、`llama3`（Ollama）
| 最大 Tokens | 单次请求最大输出长度，默认 2048
| 温度 | 创造性参数，0.0 ~ 1.0，默认 0.7
|===

点击 *测试连接* 按钮可验证配置是否正确。

=== 使用 AI 功能

打开 AI 面板（`Ctrl+Alt+A`），支持以下操作：

[cols="1,3"]
|===
| 续写 | 在光标位置继续写作，保持文档风格一致
| 润色 | 选中一段文本后，AI 帮助改进表达
| 解释 | 选中代码或文本后，AI 给出解释
| 翻译 | 选中文本后，进行中英互译
| 总结 | 选中内容后，生成要点摘要
| 自由对话 | 在输入框中输入任意指令
|===

操作方式：

. **AI 操作按钮** — 选中一段文本，点击 AI 面板中的操作按钮。
. **自由对话** — 在输入框中直接输入提示词，`Enter` 发送，`Shift+Enter` 换行。
. **插入结果** — AI 回复下方有 *插入* 按钮，点击将内容插入编辑器光标处。

所有 AI 响应均为流式输出，实时显示生成过程。


== 知识网络

方谋文构通过双向链接、标签和知识图谱，将文档编织成知识网络。

=== 双向链接

在文档中使用 `<<filename.adoc#,显示文本>>`（AsciiDoc）或 `[显示文本](filename.md)`（Markdown）创建内部链接。系统会自动：

- 在 *反向链接面板*（`Alt+B`）中显示所有引用当前文档的来源文件
- 在 *状态栏* 中显示当前文档的反向链接数量
- 点击反向链接条目可跳转到来源文件

=== 标签

在文档中使用以下语法添加标签：

[source,asciidoc]
----
// AsciiDoc 标签
[tag::标签名]

// 或在属性行中
:tags: 标签1, 标签2, 标签3
----

[source,markdown]
----
// Markdown 使用 YAML front matter
---
tags: [标签1, 标签2, 标签3]
---
----

通过 *标签面板*（`Alt+T`）可浏览所有标签，点击标签筛选相关文档。

=== 知识图谱

快捷键 `Alt+G` 打开全屏知识图谱，以力导向布局可视化文档间的链接关系。

图谱操作：

[cols="1,3"]
|===
| 浏览 | 鼠标拖拽平移画布，滚轮缩放
| 搜索 | 顶部搜索框输入关键词过滤节点
| 导航 | 点击节点打开对应文档
| 统计 | 显示节点数和边数
|===


== 自定义标记

自定义标记允许你创建常用的格式片段，并通过快捷键一键插入。适合频繁使用的模板、代码片段或格式标记。

=== 添加自定义标记

. 打开 *设置 → 自定义标记*。
. 点击 *添加片段* 按钮。
. 填写以下字段：
+
[cols="1,3"]
|===
| 名称 | 片段显示名称，如 "警告框"
| 模板 | 片段内容，使用 `{selected}` 代表当前选中的文本
| 快捷键 | 绑定的键盘快捷键
| 类型 | *行内* 或 *块级*（影响插入方式）
| 目标格式 | 留空=所有格式、`adoc`=仅 AsciiDoc、`md`=仅 Markdown
|===

=== 使用自定义标记

- 在编辑器中选中文本，按配置的快捷键插入。

== 插件系统

方谋文构的插件系统允许第三方扩展编辑器功能。插件在独立的沙箱环境中运行，不会影响核心功能的稳定性。

=== 插件目录

插件存放在工作区目录下的 `.docforge/plugins/` 文件夹中：

```
your-workspace/
├── .docforge/
│   ├── plugins/
│   │   ├── _state.json            # 插件启用/禁用状态
│   │   ├── mermaid-diagrams/
│   │   │   ├── plugin.json        # 插件清单
│   │   │   └── index.js           # 插件入口
│   │   └── word-count/
│   │       ├── plugin.json
│   │       └── index.js
│   └── ...
└── your-documents/
```

=== 插件清单 (plugin.json)

每个插件必须包含一个 `plugin.json` 清单文件：

[source,json]
----
{
  "id": "unique-plugin-id",
  "name": "插件显示名称",
  "version": "1.0.0",
  "description": "插件功能描述",
  "main": "index.js",
  "extensionPoints": {
    "toolbar": "toolbarButton",
    "editor-extension": "editorExt"
  }
}
----

字段说明：

[cols="1,3"]
|===
| `id` | 全局唯一标识符，建议使用反向域名格式，如 `com.example.my-plugin`
| `name` | 在插件管理面板中显示的名称
| `version` | 语义化版本号
| `description` | 插件功能的一句话描述
| `main` | 入口文件路径，相对于插件目录
| `extensionPoints` | 声明插件提供的扩展点及其对应的导出名称
|===

=== 扩展点

插件可以通过以下扩展点接入编辑器：

[cols="1,3"]
|===
| `toolbar` | 添加工具栏按钮，如自定义操作、快速工具
| `ai-action` | 注册自定义 AI 操作，扩展 AI 面板的功能按钮
| `exporter` | 注册新的导出格式处理器，如 EPUB、LaTeX
| `keybinding` | 注册自定义键盘快捷键和对应的编辑器命令
| `editor-extension` | 提供 CodeMirror 扩展，如自定义语法高亮、代码检查
| `preview-enhancer` | 增强预览渲染，如 Mermaid 图表、数学公式渲染
| `sidebar-panel` | 添加自定义侧边面板，如特殊导航、书签
| `status-item` | 在状态栏添加自定义状态项
|===

=== 插件沙箱环境

插件在一个受限的沙箱环境中执行，可使用以下能力：

- **控制台** — `console.log()` 等方法，输出会带插件 ID 前缀
- **事件总线** — 订阅和发布事件，与编辑器核心及其他插件通信
- **文件操作** — 受限的 IPC 文件读写（仅限工作区内）
- **搜索** — 调用编辑器的搜索功能

=== 编写插件示例

==== 示例 1：Mermaid 图表渲染插件

这个插件在预览面板中渲染 Mermaid 语法图表。

**目录结构**：

```
.docforge/plugins/mermaid-diagrams/
├── plugin.json
└── index.js
```

**plugin.json**：

[source,json]
----
{
  "id": "mermaid-diagrams",
  "name": "Mermaid 图表",
  "version": "1.0.0",
  "description": "在预览中渲染 Mermaid 流程图、序列图等",
  "main": "index.js",
  "extensionPoints": {
    "preview-enhancer": "mermaidEnhancer"
  }
}
----

**index.js**：

[source,javascript]
----
// Mermaid 图表渲染插件

export const mermaidEnhancer = {
  name: 'mermaid',
  priority: 10,

  // 在预览 HTML 渲染后增强内容
  enhance(htmlContent) {
    // 将 [mermaid] 块转换为 Mermaid 渲染容器
    const enhanced = htmlContent.replace(
      /\[mermaid\]\n([\s\S]*?)\n----/g,
      (match, code) => {
        return `<div class="mermaid">${code}</div>`;
      }
    );

    // 注入 Mermaid.js 脚本
    const script = '<script src="https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js"></script>' +
      '<script>mermaid.initialize({startOnLoad:true});</script>';

    return enhanced + script;
  }
};
----

==== 示例 2：字数统计状态栏插件

在状态栏添加实时字数统计。

**plugin.json**：

[source,json]
----
{
  "id": "word-count-status",
  "name": "字数统计",
  "version": "1.0.0",
  "description": "在状态栏显示实时字数、段落数统计",
  "main": "index.js",
  "extensionPoints": {
    "status-item": "wordCountStatus",
    "editor-extension": "wordCountUpdater"
  }
}
----

**index.js**：

[source,javascript]
----
// 字数统计状态栏插件

export const wordCountStatus = {
  id: 'word-count',
  label: '字数',
  position: 'right',       // 显示在状态栏右侧
  defaultValue: '0 字',

  // 更新显示值
  update(text) {
    const chars = text.length;
    const words = text.trim().split(/\s+/).filter(Boolean).length;
    const paragraphs = text.split(/\n\n+/).filter(p => p.trim()).length;
    return `${chars} 字 / ${words} 词 / ${paragraphs} 段`;
  }
};

export const wordCountUpdater = {
  // CodeMirror 扩展：监听文档变化，更新状态栏
  type: 'plugin',

  create(view) {
    return {
      update(update) {
        if (update.docChanged) {
          const text = update.state.doc.toString();
          wordCountStatus.update(text);
        }
      }
    };
  }
};
----

==== 示例 3：自定义导出格式插件

添加 EPUB 导出功能。

**plugin.json**：

----
{
  "id": "epub-exporter",
  "name": "EPUB 导出",
  "version": "1.0.0",
  "description": "将 AsciiDoc 文档导出为 EPUB 电子书格式",
  "main": "index.js",
  "extensionPoints": {
    "exporter": "epubExporter"
  }
}
----

**index.js**：

[source,javascript]
----
// EPUB 导出插件

export const epubExporter = {
  name: 'EPUB',
  extension: '.epub',
  formats: ['adoc'],

  // 执行导出
  async exportFile(filePath, outputPath, options) {
    // 调用外部命令 asciidoctor-epub
    const { execute } = options ipc;
    await execute('asciidoctor-epub', [
      '-a', `ebook-title=${options.title || ''}`,
      '-o', outputPath,
      filePath
    ]);
    return { success: true, outputPath };
  }
};

=== 安装与管理插件

. 将插件文件夹放入 `.docforge/plugins/` 目录。
. 打开 *插件管理面板*（`Alt+L`）。
. 插件列表中会显示所有已安装的插件，包含名称、版本和描述。
. 使用开关按钮启用或禁用插件。
. 禁用的插件不会被加载，但保留在工作区中。

=== 插件开发注意事项

- 插件 ID 必须全局唯一，避免与系统或其他插件冲突。
- 入口文件必须使用 ES Module 语法（`export`）导出扩展点。
- 插件运行在沙箱中，无法直接访问 DOM 或 Node.js API。
- 使用事件总线与其他组件通信，而非直接调用。


== 多工作区

方谋文构支持同时管理多个工作区（文档目录），每个工作区保持独立状态。

=== 工作区操作

[cols="1,3"]
|===
| 创建工作区 | 在侧栏点击 *打开目录*，选择一个新文件夹
| 切换工作区 | `Ctrl+Alt+\` 弹出工作空间选择器，或 `Ctrl+Alt+1~9` 快速切换
| 工作区状态 | 每个工作区独立保存：打开的标签页、光标位置、侧栏宽度、视图模式
|===

=== 工作区状态存储

工作区状态保存在各自的 `.docforge/` 目录中，互不干扰。即使切换工作区，前一个工作区的标签页和光标位置会被完整保留。


== 快捷切换器

方谋文构提供三套快捷切换器，均支持键盘优先操作。

=== Ctrl+Tab — 快速切换

IDEA 风格的切换器，左右两栏布局：

- **左栏**：视图与工具 — 侧栏、预览、大纲、搜索、AI 助手、反向链接、标签、知识图谱、导出历史、插件管理
- **右栏**：打开的文件 — 当前活动标签蓝色标记，未保存文件橙色圆点
- 操作：按住 `Ctrl`，`Tab` 向下翻选，`Ctrl+Shift+Tab` 向上翻选，松开激活
- 点击弹窗外区域关闭

=== Ctrl+P — 快速打开文件

- 弹出搜索框，输入文件名进行模糊搜索
- 最近打开的文件排在最前
- `↑↓` 或 `Tab` / `Shift+Tab` 导航，`Enter` 打开
- 匹配字符高亮显示

=== Ctrl+Alt+\ — 切换工作空间

- 列出最近打开的工作空间
- 输入关键词过滤，`Enter` 或点击切换

== 常见问题

=== 导出 PDF 失败

确保已安装 `asciidoctor-pdf`：

[source,bash]
----
gem install asciidoctor-pdf
----

如使用 CJK 字体，需在 PDF 设置中指定字体目录，并配置包含中文字体的主题文件。

=== 导入 DOCX 失败

确保已安装 `pandoc`。在 *设置 → 导出 → 通用* 中点击 *检测* 按钮确认工具是否可用。

=== AI 连接失败

. 检查 API 端点是否正确（注意不要遗漏 `/v1`）。
. 检查 API Key 是否有效。
. 如使用 Ollama，确保服务已启动（`ollama serve`）。
. 点击 *测试连接* 查看具体错误信息。

=== Vim 模式无法退出 Insert

默认退出序列是 `jk`（快速连续输入）。可在 *设置 → 编辑器 → Vim 退出序列* 中修改为你习惯的序列。

=== 图表不渲染

在 *设置 → 导出 → AsciiDoc · 引擎* 中勾选 *启用 asciidoctor-diagram*，并确保已安装：

[source,bash]
----
gem install asciidoctor-diagram
----

= 方谋文构 (Fangmou DocForge) 架构文档

一款为"思想工程师"打造的 AI 原生、可扩展的本地文本编辑器。写作，本应如工程。

== 技术栈

|===
| 层 | 选型 | 说明
| 桌面框架 | Tauri v2 | Rust 后端，体积 ~10MB
| 前端 | Lit 3 (Web Components) | 无框架依赖，~5KB gzip
| 编辑器 | CodeMirror 6 | 可扩展编辑器引擎
| AsciiDoc 渲染 | @asciidoctor/core | 浏览器端渲染
| AI 集成 | OpenAI 兼容 API | 支持 OpenAI/Ollama/DeepSeek 等
| 构建 | Vite 6 | 前端构建工具
|===

=== 数据流标准模式

文件内容派生数据（链接、标题、标签、大纲）统一由 Rust 解析 + SQLite 存储，前端只做薄 IPC 代理。UI 状态（标签页、光标、面板可见性）保留在前端。

|===
| 分类 | 前端职责 | 后端职责

| 文件内容派生数据 | IPC 代理 + 缓存标题 | 解析 + SQLite 存储
| UI 状态 | 标签页/光标/脏标记 | 无
| 纯 IPC 代理 | 调用 | 执行（file/search/config）
| 可视化计算 | graph-layout 力导向布局 | 无
|===

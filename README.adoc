== 方谋文构是什么？

一款为"思想工程师"打造的桌面文本编辑器。将软件工程的纪律赋予写作——纯文本根基、版本控制友好、AI 深度集成、知识网络化管理。没有云端锁定，没有私有格式，你的文字永远属于你自己。

== 功能亮点

- **AsciiDoc 编辑器**：CodeMirror 6 + 25+ 语法自动补全 + 实时双栏预览
- **AI 辅助写作**：流式续写/润色/翻译/总结，支持 OpenAI、Ollama、DeepSeek 等
- **知识网络**：双向链接 + 反向引用 + 标签体系 + 力导向知识图谱
- **多工作区**：项目间快捷切换（Ctrl+Alt+1~9），自动恢复上次状态
- **全文搜索**：Rust 引擎驱动，支持正则，跨文件搜索替换
- **导出发布**：HTML（响应式模板）/ PDF（asciidoctor-pdf 集成）
- **插件系统**：Worker 沙箱隔离，8 个扩展点（工具栏/AI动作/导出/编辑器/预览/侧栏/快捷键/状态栏）
- **中英双语**：完整的国际化支持，新增语言只需添加 JSON 文件
- **全平台**：Linux / Windows / macOS

全部 32 项功能需求已完成，详见 link:docs/requirements/README.adoc[需求追踪]。

== 项目结构

DocForge/
├── src/
│   ├── components/       # Lit Web Components（editor / preview / ai-panel / graph-view ...）
